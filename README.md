# Neurotec - Biometric Fingerprint Scanning Solution

## Overview

**Neurotec** is a modern, enterprise-grade biometric fingerprint scanning solution designed to replace legacy VFS biometric systems. Built with .NET Core and Windows, it provides a seamless, single-installer deployment model with automatic service initialization and real-time biometric capture capabilities.

The system replaces a decade-old solution with improved performance, easier deployment, and reduced maintenance overhead through an intelligent Windows Service that handles all backend operations.

---

## Key Features

✅ **Single-Click Installation** - One installer (`Neurotec_Biometric_v1.0.msi`) deploys everything  
✅ **Automatic Windows Service** - Auto-starts on boot with no manual configuration  
✅ **Neurotec SDK Integration** - Automatic SDK initialization and USB device detection  
✅ **Web-Based UI** - Modern web interface served directly from the Windows Service  
✅ **Real-Time Fingerprint Scanning** - Live biometric capture and quality analysis  
✅ **Zero External Dependencies** - No separate Node.js, React server, or complex setup needed  
✅ **Enterprise-Ready** - Built on .NET Core for reliability and scalability
